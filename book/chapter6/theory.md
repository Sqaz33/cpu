# Специализированные вычисления

## Вычисления в реальном времени

Требования к времени реакции на изменения входных данных: предельные сроки, огр. время, которое может протреб. сист. для формирования выходных данных в ответ на изменение входных данных.

## RTOS

Почти все элементы - должны удовл. треб. врем.

Вытесняющая многопоточность.

## Цифровая обработка сигналов

(digital signal processor, DCP)

Процессор с АЦП и ЦАП, оптимизированный для обработки оцифрованного аналогового сингала.

### АЦП и ЦАП

АЦП - измеряет входное напр. и выдает на выходе цифр. слово, предст. это напр. ЦАП - приобр. цифр. слово в напр.

*Разрешение* - максимальное количество бит на входе/выходе.

*Макс. скорость преобр.* - скорость быстро может выдасть последовательные вых. дан.

Основ. опер, вып. при скал. скаперемножении векторов - *умножение с накоплением (multiply accumulate, MAC)*. Матем. производительность DSP - кол. MAC в сек.

### Аппаратная часть

Модифицированная Гарвардская архетиктура - данные отдельно от программы, но можно хранить некоторые даные в инструкциях.

## Алгоритмы абработки сигнала

### Свертка (Свертка последовательностей)

Как обычное скаляр. перем. только индексы одной последовательности берутся в обратн. порядке

Во многих практ. прил.: один вектор - вектор в памяти, второй - последовательность выборок из АЦП.

Тут свертка - скалярное произв. вектора из памяти размером n и вектора из n последних измерений АЦП.
